# Workplace notes

## Access
Badge access covers all wings from 07:00 to 21:00 on weekdays. The server room
requires an additional permission that is granted per project.

## Desks
Desks are unassigned. Teams cluster loosely by wing, and the per-wing desk counts
are shown on the floorplan rather than listed here so the plan stays the single
source of truth.

## Meeting rooms
Meeting rooms are bookable in fifteen-minute blocks and are released
automatically if nobody checks in within five minutes.
