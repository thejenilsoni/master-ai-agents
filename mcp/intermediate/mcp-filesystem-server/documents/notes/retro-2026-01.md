# Retro — January 2026

Present: platform rota, two guests from support.

## What went well

- The seeded local environment cut new-joiner setup from two days to an hour.
- Nobody had to page the on-call engineer during the release window.
- Search latency dropped after the index rebuild.

## What did not

- Two incidents traced back to a path handling bug: a request with `..` in it
  reached a file outside the intended directory. We shipped a fix that resolves
  every path and rejects anything landing outside the sandbox root.
- The weekly staging refresh silently failed for eleven days.

## Actions

1. Add regression tests for path traversal and symlink escapes.
2. Alert when the staging refresh has not run for 48 hours.
3. Write down the release checklist instead of remembering it.
