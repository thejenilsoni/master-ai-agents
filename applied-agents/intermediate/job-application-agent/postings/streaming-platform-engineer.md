# Senior Platform Engineer, Streaming

**Company:** Northgate Freight
**Location:** Bristol, UK (hybrid, 2 days in office)

We move parcels, and we are rebuilding the systems that track them. The events
platform is the backbone: every scan, every exception, every customer
notification flows through it. You would own it.

- 5+ years building backend services in Python
- Production experience with Kafka or a comparable event-streaming system
- Strong PostgreSQL: schema design, query tuning, and upgrades you have actually
  run rather than read about
- Infrastructure as code — we use Terraform across three AWS accounts
- A track record of improving observability on systems you did not originally
  write

## Nice to have

- Experience with Airflow or another orchestrator
- Exposure to Kubernetes
- Open-source contributions
- Experience mentoring engineers
