# Tessera — Plans

Tessera Standard is $45 per user per month on an annual contract.

There is no free tier; evaluation is by a 21-day trial.

Tessera publishes a 99.9% uptime commitment for Standard and above.

Tessera operates in 4 cloud regions.

Single sign-on is included from the Standard plan upwards.
